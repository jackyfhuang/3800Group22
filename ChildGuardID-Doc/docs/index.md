# <h1 style={{ textAlign: 'center' }}>Overview</h1>

Welcome to the ChildGuardID handoff guide. This document is designed to help you launch, explore, and demonstrate the application using the files provided in your project folder.

---

## Intended Users

This guide is written specifically for project owners and stakeholders. No coding experience is required to follow these instructions.

## Prerequisites
---

To run the ChildGuardID demo, please ensure you have the following:

1. **A Windows PC or Laptop** | The automated setup is designed for a Windows environment.

2. **The Project Folder** | Ensure the "ChildGuardID" folder is unzipped and saved to your desktop.

3. **Internet Connection** | Required only for the initial one-time setup to download necessary components.

4. **An Android/iOS Phone (Optional)** | If you wish to view the app on a physical device rather than a computer screen.

5. **Expo Go App** | Ensure you have downloaded the Expo Go app on phone(s) for demo purposes.

## Software Requirements
---

The automated setup will attempt to install these for you, but they are required for the app to function:

- [**Node.js**](https://nodejs.org/en/download) | The engine that powers the app's interface  
- [**Mobile Simulator (Optional)**](https://chromewebstore.google.com/detail/mobile-simulator-responsi/ckejmhbmlajgoklhgbapkiccekfoccmk) | A Chrome extension that allows you to preview the app in a mobile view on your computer
